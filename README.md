# Laravel 12 + React 19 

Aplicación web construida con **Laravel 12**, **React 19**, **Inertia.js v2**, **Tailwind CSS v4** y **TypeScript**. Incluye soporte para autenticación con Fortify, gestión de roles y permisos con Spatie, generación/visualización de PDFs, exportación a Excel/CSV y componentes de UI basados en Radix UI y Lucide.

---
**Backend**
- **Framework:** Laravel `^12.0`
- **PHP:** `^8.2`
- **Autenticación:** Laravel Fortify `^1.30`
- **Permisos y Roles:** Spatie Laravel-Permission `^6.21`
- **Integración SPA:** Inertiajs inertia-laravel `^2.0`
- **Enrutamiento JS:** Ziggy `^2.6` & Wayfinder `^0.1.9`
- **Reportes & Archivos:** Maatwebsite Excel `^3.1` & League CSV `^9.28`

---
**Frontend**
- **Librería UI:** React `^19.0` (TypeScript `^5.7`)
- **Bundler:** Vite `^7.0`
- **Estilos:** Tailwind CSS `^4.0` (`@tailwindcss/vite`) + `tailwindcss-animate`
- **Componentes UI:** Radix UI primitives, Headless UI, Lucide React icons (`^0.562`)
- **Formularios & Validación:** React Hook Form `^7.69` + Zod `^4.2` + Hookform Resolvers
- **Arrastrar y Soltar (Drag & Drop):** `@dnd-kit` (`core`, `sortable`, `modifiers`)
- **Visualización de datos & PDFs:** Recharts `^2.15`, React PDF Viewer / Renderer, jsPDF
- **Notificaciones:** Sonner `^2.0` / React Toastify `^11.0`

---
**Requisitos Previos**
- **PHP:** `>= 8.2`
- **Composer:** `>= 2.x`
- **Node.js:** `>= 18.x`
- **Base de Datos:**  SQL Server
